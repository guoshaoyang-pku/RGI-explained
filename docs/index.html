Why can different training algorithms produce similar loss fluctuations? In a finite Pythia-70M continuation, we measure the batch difficulty and the local learning response separately. The shared data term dominates raw loss variation; negative work and positive curvature account for most of the smaller response.为什么不同训练算法会出现相似的 loss 波动？在有限的 Pythia-70M 续训中，我们分别测量 batch 难度和局部学习响应：数据项主导原始 loss 的起伏，负的一阶作用与正的曲率项共同解释较小的学习响应。

What the decomposition explains这几个项解释了什么

A difficult next-token target can raise the loss of several models at once. Teacher forcing holds the real prefix and target fixed, so D measures that batch with a frozen model. After subtracting D, the actual displacement produces first-order work A and a nonnegative logit curvature cost Q₂. Their partial cancellation makes the net learning response smaller than either contribution. Both contributions change with the optimizer.

一个较难预测的目标 token，可以同时提高多个模型的 loss。Teacher forcing 固定真实前缀和目标，让 D 用冻结模型测量同一 batch 的难度。扣除 D 后，实际位移产生一阶作用 A 和非负的 logit 曲率代价 Q₂；两者部分抵消，使净学习响应比单项贡献更小。优化器会同时改变这两项。

The exact starting point is the cross-entropy identity精确起点是交叉熵恒等式

M = L − D = W + Q = A + R + Q
W = mean (p₀ − ey)ᵀΔz   ·   Q = mean KL(p₀ ∥ pt) ≥ 0
R = W − A   ·   ε = R + (Q − Q₂)

Here p₀ and pₜ are the frozen and current conditional distributions, eᵧ is the observed target, and Δz is the actual logit displacement. A uses the parameter displacement; Q₂ is the second-order approximation of Q in logit space.

p₀、pₜ 分别是冻结和当前模型的条件分布，eᵧ 是实际目标，Δz 是实际 logit 位移。A 使用参数位移；Q₂ 是 Q 在 logit 空间中的二阶近似。

This identifies measured contributions on completed trajectories. It does not predict an unknown future update. The coefficient 1 on D follows from the decomposition itself; it does not establish a shared first-order optimizer response coefficient. We also do not assume that batch difficulty and learning response are independent.

这里定位的是已完成轨迹上的实测贡献，不能预测尚未发生的更新。D 前的系数 1 来自分解恒等式，不能据此证明不同优化器具有相同的一阶动力学系数；我们也没有假设 batch 难度与学习响应统计独立。

Does natural text provide the true conditional distribution?自然语料是否给出了真实条件分布？

Natural text supplies one observed next token per prefix. It does not reveal the full true conditional distribution. The natural-data D is therefore frozen-model cross-entropy, not a known Bayes entropy. A separate known-teacher experiment lets us check the local response against full teacher probabilities; it still fails the strong constant-offset test.

自然文本对一个前缀只提供一个实际 next token，没有给出完整的真实条件分布。因此自然数据上的 D 是冻结模型交叉熵，不能称为已知的 Bayes 熵。另一个已知 teacher 实验允许我们用完整 teacher 概率检验局部响应，但它仍未通过强常数偏移检验。

Where the stronger explanation fails更强解释的实质性阻碍

Relative generalization invariance (RGI) asks for an approximately sample-independent loss difference across models. Explaining each trajectory locally is a weaker result. The stronger tests below retain their failures.

相对泛化不变性（RGI）要求模型间的 loss 差近似不随样本变化。分别解释两条轨迹的局部响应，是更弱的结论。下面保留更强检验的失败结果。

Experiment and evidence实验与证据

Pythia-70M; FineWeb sample-10BT; 512 continuation updates; batch 8; context 256. The three permutations reuse one 4,096 / 64 / 512 train / calibration / evaluation pool. SGD uses lr 0.001; Adam uses lr 10⁻⁶ and betas (0.9, 0.95). Each algorithm begins at its own prior endpoint, with optimizer state reset. The common difficulty reference is official step 32,000.

Pythia-70M，FineWeb sample-10BT，512 次续训更新，batch 8，context 256。三种排列共享同一 4,096 / 64 / 512 的训练 / 校准 / 评估池。SGD 的 lr 为 0.001，Adam 的 lr 为 10⁻⁶、betas 为 (0.9, 0.95)。每个算法从各自先前阶段的终态开始，起点重置优化器状态；共同难度参考为 official step 32,000。

The public release includes the manuscript, aggregate analyses, chart values, and integrity/arithmetic checks. Raw weights, full logits, text data, and complete training producers are not included. This supports inspection of the reported results, not full training reproduction. It is a finite continuation study, not a reproduction of the original paper’s from-scratch LLM experiments.

公开内容包括论文、聚合分析、曲线数据，以及完整性和算术检查。原始权重、完整 logits、文本数据和完整训练生产脚本未收录。因此它支持检查已报告结果，尚不能完整复现训练；本研究是有限续训，也没有复现原论文从头训练 LLM 的实验。
