# Contributing

Use Python 3.9+, XeLaTeX and latexmk. Run ./setup.sh, python3 verify_evidence.py and the build command in README.md.

Use a focused branch and explain the evidence for changed equations, numbers or scope. Preserve retrospective versus forecast distinctions and failed gates.

For build issues, include commands and versions. Remove private paths and credentials from attached logs. Review NOTICE.md before reusing brand assets.

If using Codex or Claude Code, read AGENTS.md. Rebuild the PDF and update the file manifest after intended release-file changes.
